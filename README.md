# Overlook
Projeto para a disciplina de Projeto e Desenvolvimento de Jogos da PUCRS em 2024.

Jogo baseado no filme e livro "O Iluminado".

Jogo ambientado no hotel assombrado Overlook, em que Danny, um garoto de 8 anos, deve fugir de seu pai possuído Jack. Para isso, Danny deve achar as chaves de três áreas diferentes do hotel com a ajuda dos Fantasmas que ali habitam.

Fase 1: Hall do Hotel

Fase 2: Andar dos quartos

Fase 3: Labirinto externo
